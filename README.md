# Inventory Management Syste

## Project Overview
Inventory Management System developed using Python and MYSQL.

## Technologies Used
- Python
- MYSQL
- MYSQL connector/Python

## Features
- Add, Update and remove products
- View inventory
- Manage customers
- Shopping cart
- Generate bills
- Calculate total revenue
- Update stock after successful purchases

## Database Tables
- products
- customers
- orders
- order_items

## How to Run 
1. Install Python and MYSQL.
2. Execute schema.sql in MYSQL Workbench.
3. Install the dependency:

    python -m pip install mysql-connector-python

4. Configure MYSQL credentials in database.py.
5. Run:

    python main.py
